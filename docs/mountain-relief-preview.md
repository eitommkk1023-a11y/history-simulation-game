# 山脈の起伏調整・プレイ用プレビュー

生成版14。若い造山帯のみ既存ridgedノイズの周波数を0.011から最大0.008へ下げ、描画頂点間約19.5kmで捉えやすい起伏にする。尾根の振幅をノイズ値と年代に応じて調整し、峰と鞍部の差を強める。古い山地、全体解像度、気候・侵食・火山の計算方式は維持。版11〜13の保存は対応する生成経路で復元。

評価基準は1倍＝実寸のリアリティ、1.5〜2倍＝ゲームの見やすさ、10倍＝問題調査。倍率は物理に影響しない。

プレビューはgh-pagesのpreview/以下。index.htmlは開始・HTMLダウンロードの案内、game.htmlは単一HTMLの実行ファイル。公開版ルートのindex.htmlは変更しない。配布コピーのIndexedDB名だけgeo-world-preview-savesへ変更し、公開版の保存データと隔離する。

全画面はゲームの既存ボタンを使用。対応しないiPhone/iPadのSafariはホーム画面へ追加して起動する。実機互換性は未検証。

検証：Seed549589336で最高6326.94m・陸地44.538%、822295939で最高7403.93m・陸地44.5395%。外周海、有限標高、3表示モードの物理標高/カメラ不変、保存復元の継続一致、噴火、リセットを確認。1/1.5/2倍の画面を撮影して確認した。既存解像度の滑らかさは残る。
