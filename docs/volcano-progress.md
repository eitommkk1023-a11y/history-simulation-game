## 残る検証と課題

1. iPhone/iPad実機・Safariでの描画負荷、初期生成、保存操作の確認。
2. 色テクスチャは局所色更新に必要な36MBのCPUデータを保持する。GPUへの転送は現状全体で、最適化余地がある。
3. 初期の世界全体の生成・約3000²セルのデータ量は既存構造を維持。スマートフォンのメモリ上限は実機で確認が必要。
4. Claude向け統合資料と近似モデルの限界は `docs/volcano-handoff.md` に記載。

## 制約と技術上の留意点

- 既存地形1セル3330m、描画メッシュ約19.5kmなので噴火近傍のみ416.25mの細格子を使用。
- 物理値はSI単位。表示倍率は物理値を変更しない。
- 物理Worker、固定シミュレーション刻み、端末性能に応じて作業を分割しても結果を変えない。
- 溶岩体積と火砕物の空隙を含む堆積体積を区別し収支を記録。
- 河川のrec等は現在worldに保存されていない。本実装は既存の河川折れ線を利用。
- 旧セーブはSeed再生成依存。生成器変更時に旧生成経路を保持して復元を確認する。
- 全火山噴火ボタンは削除候補としてユーザーに提示したが、削除承認はまだない。
- 噴煙/雨雪の粒子密度、遠景の文字、描画ピクセル比は物理に影響しない品質調整候補。
