# 火山計算コア

`src/volcano-core.js` をHTMLの `volcano-src` に埋め込み、専用Worker内で実行する。Nodeでも同じ実装をテストする。`node tools/embed-volcano.cjs` が配布HTMLを同期する。

## 単位・決定性

座標APIのx/yだけが既存の地図ブロック。内部セルは8分割（実地図では416.25m）、距離m、体積m³、温度℃、時間は固定6時間刻み。1年360日。画面の高さ倍率は入力に含めない。乱数状態を保存する。同じエンジンと入力に対して時間送りの分割・保存復元による結果を比較する。異なるブラウザーの超越関数の最下位bit一致は未保証。

## 公開API

- `decorate(volcanoes, geology, seed, sampleHeight)`：形態・カルデラ構造・陸上/海底立地、4組成、マグマ状態を生成。
- `create({width,height,metresPerBlock,elevation,volcanoes,geology,seed,day,climate,river})`：不変の基盤地形をコピーしてEngineを生成。
- `erupt(id,level)`：活動火山のみ1〜4の要求を受付。使えるマグマから予約し、継続的に供給。
- `advanceTo(day)`：整数日まで更新。静止期間は月境界まで飛ばす。
- `drainChanges()`：粗格子の絶対標高差分、全占有細格子、火山状態、イベント、空の霞み、収支を取得。
- `heightAt(x,y)`、`measure()`、`snapshot()`、`restore(snapshot)`。

## 数値モデルと制限

初期噴出量の段階は100万/1000万/8000万/4億m³に圧力補正を加え、蓄積量で制限。継続時間は規模・圧力・粘性・供給・噴出口数で決める。これらは軽量なゲーム用近似で、噴火予測式ではない。

溶岩は同一時刻の地表+溶岩高度から8方向へ分配。送出量を保有量以下に抑え、体積と熱を同時に受け渡す。表面と内部の温度を別々に近似し、厚みで内部冷却時間が延びる。海中では表面冷却のみを強める。固化した量は流動から外して地形に残す。

収支は岩石換算体積(DRE、密度換算の基準2600kg/m³)。溶岩の膨張率1、灰3.5、軽石5、火砕物2.4（非溶結珪長質条件では3.3）。粗格子で平均1cm未満の灰は標高に加えず内部収支に保持。境界外への流出も記録。

火砕流は地形とエネルギー水頭から到達域を近似し、移動に伴う損失を扱う。灰の輸送は風向風速に基づく近似分布。侵食・ラハールは堆積層のみを対象に月次更新し、既存河川の折れ線と局所勾配を利用。詳細な流体、熱伝導、破砕、海流、斜面崩壊は扱わない。

マグマ供給は月次。長い無噴火期間と弱い供給で休止し、蓄積圧力と決定的乱数で再活動。自然噴火はしない。50年の休止判定などの係数は可調整な近似値。

## 検証

`node tests/volcano-core.test.cjs`：26件。地形入力の不変性、4規模、保存則、谷と斜面、海中冷却、Seed・送り方再現性、保存継続、不正保存拒否、降灰、尾根越え、火砕流堆積、雨による再移動、流動停止、反復噴火、休止と再活動。

ブラウザー統合・実機性能は別途検証する。数値テストが通ることを実機対応済みと扱わない。
