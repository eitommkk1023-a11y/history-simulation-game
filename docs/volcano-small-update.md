# 火山小型アップデート

- 噴火後だけだった既存の8分割細密メッシュを、近距離の火山にも適用。カメラ付近の1火山、半径最大8地図セルを対象とし、離れると不要なパッチを解放する。世界全体の512分割は維持。元標高の火口・山腹・山頂を粗い世界メッシュより細かく表示する。元標高の解像度を超える新しい地形は捏造しない。
- 地質等の表示レイヤーによる溶岩色の上書きを修正。既存の内部温度・表面温度・未固化率で、流動中の明るさと冷却後の暗い岩色を切り替える。表面が冷えて内部が流動中の場合の赤熱表現は簡略化したもの。
- 流動・堆積・海底冷却・島形成の計算方式は既存の保存的モデルを維持し、28件の数値テストで確認。実スケールで6回の反復噴火から複数セルの新しい陸地を形成するテストも成功。
- 構文/表示3件、噴煙/時間進行/冷却色3件も成功。合計34件。
- Chromiumのタッチ画面で噴火前の細密パッチ生成、噴火・噴煙、時間経過、保存復元後の同一結果、実験リセット、表示設定、全画面を確認。iPhone/iPad実機のSafariは未検証。

ユーザーの今回の指示に基づき、地理生成版14を含む現在の作業ブランチをmainへ統合し、gh-pagesのルートindex.htmlへ配布する。preview/の保存先は別のまま維持。
