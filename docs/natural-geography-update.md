# 自然地理生成版13

## 変更
- 地殻厚・造山年代から標高圧縮の上限を連続的に決定。強い若い厚い地殻でのみ上限が9000mへ近づく。特定の峰は強制しない。
- 既存ridgedノイズの尾根/谷の振幅を造山年代で調整。大陸衝突のstampGeoの幅を強度に応じて変更。
- 既存の30百万年の計算、古い造山帯の減衰、気候計算後の河川/氷河侵食、三角州/リアス/フィヨルド処理を再利用。
- 初期地殻の核の数・配置・縦横比・輪郭を変化させる。初期核の一部に同じ座標変形を共有する裂け目を刻み、対向する縁に対応を残す。分裂や大陸数を保証しない。既存の古い縫合帯と大陸核の分類を使用。
- 巨大高原と内海/海峡の強制生成は版13では停止。版11/12の生成経路は旧保存用に維持。
- 標準/平均化なし/山岳優先の3ボタン。既存の地形ジオメトリを再利用して頂点/法線を更新。河川、目印、地名、噴煙の基点、火山細密描画が追従。カメラ/Seed/物理標高を変更しない。表示設定を保存。
