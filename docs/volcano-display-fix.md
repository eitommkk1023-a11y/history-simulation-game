# 噴煙表示・操作修正

ユーザー報告：噴火ボタンを押しても噴煙が見えない。通知が画面を覆う。

- 噴煙を12火山までに制限したコードを撤去。15回の成功した噴火に対して12個しか生成されないREDを確認後、15個生成するGREENを確認。
- 高さ尺度の変更時に残った旧単位の噴煙速度・拡散・粒子サイズを噴煙高度に合わせる。遠景で粒子が消えない最小表示サイズを設定。
- 噴火途中の保存復元で予約噴出データから噴煙を再作成。
- イベント通知ポップアップを無効化。履歴の記録と閲覧は継続。
- 高さ10倍・20倍を追加。物理は変更しない。
- 全画面の開始/終了ボタン。標準API・WebKit APIを判別。非対応端末ではSafari「共有 → ホーム画面に追加」の案内を表示。既存のapple-mobile-web-app-capable設定を利用。

検証：数値28件、表示/構文2件、噴煙上限の回帰1件。ブラウザでは実際の噴煙粒子のアルファ値、通知なし、全画面の開始/終了、高さ倍率変更時の標高不変、保存/復元後の物理一致、実験リセットを確認。iPhone/iPadの実機確認は引き続き未実施。
