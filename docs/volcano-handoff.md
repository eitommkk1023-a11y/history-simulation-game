# 火山アップデート：Claude Codeへの引き継ぎ

## 成果物と同期

作業ブランチ `feature/volcano-system`。mainへの統合・公開は実施しない。

- `自然地理生成器.html`：既存の単一HTML配布形式。Three.js r128を継続。
- `src/volcano-core.js`：数値計算。生成Workerと火山Workerで共有。
- `src/volcano-ui.js`：本体の閉包内に埋め込むDOM・描画・Workerアダプター。
- `node tools/embed-volcano.cjs`：上記2ファイルからHTMLを更新。埋め込み部分を直接修正しない。

## 接続箇所

地理生成版12は既存プレート/ホットスポット情報から火山を装飾し、形態に応じた初期山体を生成。版11は旧地形生成経路を保持する。火山数はSeed依存で最大90、40/50固定ではない。

`onWorldReady`が基盤地形を確定してWorkerを初期化する。`clockAfterStep`から整数日を送信し、Workerは固定6時間刻みで物理計算、月単位でマグマ・侵食を更新する。自然噴火は発生させない。

`applyVolcanoChanges`は粗地形標高・陸海判定・生態環境の陸地比・該当メッシュ・河川描画を更新。噴火周囲のみ416.25mの細格子パッチを作り、粗メッシュの該当部分をマスクする。固化後は溶岩の流動更新を停止し、堆積地形は残す。名称は既存の火山IDと名称管理を利用する。

`serializeState()`は**非同期**になった。呼び出し元は`await`する。火山Workerへの保存要求は噴火・時間進行と同じキューを通す。乱数、流動途中の温度、予約噴出量、地形堆積量を保存する。旧セーブは版11で再生成してから旧差分を反映する。

物理はm・m³、地図座標のAPIのみブロック単位。高さ倍率1/1.5/2は描画だけで変更し、初期1.5。改名は長押しまたは火山メニューの改名ボタン。短いタップは個別火山メニュー。休止中は4段階の噴火操作を無効化。

## 測定値と最適化

Node 24・このクラウド環境・64²粗格子の固定条件。描画、3000²世界生成、端末の性能は含まない。単発測定であり保証値ではない。

| 条件 | 時間 | 保持する細セル | 保存サイズ |
| --- | ---: | ---: | ---: |
| 噴火なし90火山・100年 | 6ms | 0 | 35KiB |
| 4火山同時噴火・1年 | 94ms | 4097 | 887KiB |
| 1火山の冷却後堆積物・さらに約100年 | 5185ms | 2687 | 650KiB |

侵食で1mm未満の薄い被覆を毎月移送し続ける処理を停止。量は地形・収支に残し、新たな堆積で再び計算対象になる。対応前の100年試験は21786ms/8495セル/2086KiBだった。体積を消して軽量化する処理は行っていない。

## 近似と残る制約

- 本モデルは科学的関係を取り入れたゲーム用の近似。噴火予測や精密な熱流体シミュレーションではない。
- 416m未満の細い溶岩流や噴出口は解像しない。火砕流はエネルギー経路、降灰は重み付きサンプル、軽石漂流は風に基づく簡略化。灰の分布は細格子で斑状になる場合がある。
- 既存河川の経路を侵食に再利用し、描画の標高を更新する。全河川網の再生成や流域変更を解く実装ではない。
- 地形テクスチャのCPU配列36MBを局所色更新・コンテキスト復元のため保持。メッシュ更新は局所だが、テクスチャ転送は全体。世界全体の既存データと基盤地形のコピーもメモリを使う。スマートフォンのメモリ上限は未測定。
- 固化セルは流動計算から外すが、永続地形として記録する。新規噴火域が広がればセーブサイズは増える。空の演出・イベント等の一時状態には上限を設けている。
- 静止期間は月境界へ飛ばす。侵食する堆積域が広い場合、長期一括送りはWorker内でも時間を要する。
- 数値のSeed再現性を検証。異なるJSエンジン間の浮動小数点の最下位bitまでは保証しない。煙・雨粒の描画乱数は物理に使わない。

## 削減候補

物理を変えずに削減できるのは煙・雨雪の粒子数、遠景の名称ラベル数、画面の描画解像度。今回タッチ端末のピクセル比を最大1.5に制限した。全火山同時噴火の実験ボタンは既存機能のため維持し、新しい物理へ接続した。物理セル解像度や侵食頻度の削減は結果を変えるため、無条件に削ってよい要素とは扱わない。
