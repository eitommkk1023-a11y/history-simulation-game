# 表示メニューのスクロールと風・波

原因：documentのtouchmoveリスナーがinput/.scrollable以外のpreventDefaultを行っており、表示メニューは対象外だった。CSSでoverflowを付けるだけではスワイプできなかった。

修正：専用のdisplayBody.scrollableを設け、固定見出しと内部の縦スクロールを分離。min-height:0、pan-y、慣性スクロールを指定し、横画面でも高さ倍率が操作できるようにした。

追加：表示メニューの「風の動き」「波の動き」。既存の月別風向・風速を使い、吹く方向へ動く矢印を表示。波は専用の波浪データ/モデルを追加せず、風に応じた海面の動きの可視化。海流・津波・うねりの予測表示ではない。海セルだけに波線を描く。独立したCanvas2Dレイヤーで約160か所を最大15fpsで描画し、地理・物理計算を変更しない。オン/オフをセーブへ保存。旧保存では両方オフ。

検証：Chromium 812×375のタッチ画面で、Input.dispatchTouchEventによるスワイプでscrollTopが増え、高さ20倍の選択欄が画面内に届くことを確認。風/波の両方で描画、時間による画像変化、設定の保存、両方を消すと描画が消えることを確認。ページ例外なし。表示/構文2件と噴煙/再生状態2件も成功。Safari/iPhone/iPad実機は未検証。
